# 🩺 AI Sehat – Smart Healthcare Solutions for Pakistan

AI Sehat is a frontend-based healthcare web application designed to provide quick medical guidance using AI-powered chatbot logic. The project focuses on improving access to healthcare information, especially for rural and home-bound patients in Pakistan.

---

## 📌 Project Overview

AI Sehat simulates a smart healthcare platform where users can:
- Interact with an AI health chatbot
- Get basic medical guidance based on symptoms
- Simulate online doctor consultations
- Learn about healthcare challenges and AI-based solutions
- Register as volunteers for healthcare support

This project is a **prototype** built using **HTML, CSS, and JavaScript only**, without any backend or database.

---

## 🎯 Target Users

- General public seeking first-aid or basic medical guidance  
- Patients in remote or underserved areas  
- Students and volunteers interested in healthcare support systems  

---

## 🚀 Features

- 🤖 **AI Health Chatbot**
  - Symptom-based responses using JavaScript logic
  - Multiple AI specialties (General Physician, Cardiologist, Dermatologist, etc.)
  - Cross-specialty symptom matching

- 🩺 **Online Doctor Consultation (Simulation)**
  - Patient intake form
  - AI specialist-based chat interaction

- 🧑‍🤝‍🧑 **Volunteer Registration**
  - Form for volunteers to apply in different healthcare areas

- 🌙 **Dark Mode**
  - Toggle between light and dark themes

- 🎨 **Modern UI/UX**
  - Responsive design
  - Card animations
  - Loader animation

---

## 🛠️ Technology Stack

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS)
- **Backend:** None (Frontend-only prototype)
- **Database:** None
- **Version Control:** Git & GitHub
